# Quantalyt — Autonomous AI Systems & Enterprise Web Platform

Official codebase for **Quantalyt**, an enterprise AI agency specializing in autonomous cognitive agents, human-parity voice telephony automation, and ultra-high-velocity Next.js web applications.

---

## 🚀 Key Features

- **Next.js 14/15 App Router & TypeScript**: Production-ready, sub-second global edge performance with full SEO and JSON-LD schema.
- **Scroll-Driven Micro-Interactions**:
  - Top fixed glowing laser progress indicator.
  - Scroll-linked 3D perspective rotation on the chrome emblem.
  - Kinetic text illumination / word scrubber on scroll.
  - Sticky stacked cards for core service architecture.
  - Animated laser roadmap for sprint delivery phases.
- **NVIDIA DeepSeek-R1 AI Assistant**: Integrated streaming conversational engine with custom prompt management.
- **Live Voice Agent Simulator**: Real-time fluctuating audio waveform and interactive telephony qualification transcripts.
- **Interactive Executive ROI Estimator**: Dynamic sliders for team size, manual hours, and projected dollar savings.
- **Admin Panel & Dedicated CRM**:
  - Real-time visitor logs with geo-location.
  - Lead qualification pipeline & status management.
  - Full chat session transcripts explorer.
  - NVIDIA NIM DeepSeek API key tester and prompt editor.
- **Omnichannel Direct Connect**:
  - One-click phone hotline (`0339 7444694`).
  - Pre-filled WhatsApp direct chat.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router) + [React](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) + [Lenis](https://lenis.darkroom.engineering/)
- **Database / Backend**: [Supabase](https://supabase.com/) (PostgreSQL)
- **AI Core**: [NVIDIA NIM](https://build.nvidia.com) (DeepSeek-R1) + [OpenAI](https://openai.com)
- **Auth**: [NextAuth.js](https://next-auth.js.org/)

## 🏁 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/muazahmedbhati-stack/quantalyt.git
cd quantalyt
```

### 2. Install dependencies
```bash
npm install
```

### 3. Environment Variables
Copy `.env.example` to `.env.local` and configure your credentials:
```bash
cp .env.example .env.local
```

### 4. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
